**3. In your own words — after playing — what is a table, a row, a column, and a query?**

A table is container of grouped information that consist of rows and columns of which can hold various data types.<br>
A row is the horizontal line that runs accross the table, the first row being the headers of each column, which specifies the expected data inside. For example name, we would expect names in the following rows.<br>
A column is the vertical column that runs down the table, it contains the ifnroation and data type specified by the header row, for example, if the header row in villageid, the column below would contain the numerical value of each profile that exist in the table.<br>
